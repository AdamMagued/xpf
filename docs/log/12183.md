# #12183 — resolve mixed-static recursive backup routes

- **Issue**: #12183 — mixed direct/recursive static ECMP rows retain a bare recursive next hop, leaving the live backup without an egress.
- **Branch**: `fix/12183-campaign-pub`
- **Worktree**: `/var/worktrees/campaign-pub/wt-12183`
- **Base**: `83b5c955335f16d8c7835f206b210ce3ae1a5fe5`

## Why

The Go snapshot preserves a mixed static row containing a direct member and a recursive member. The Rust userspace FIB previously treated the recursive gateway as connected-only, leaving its next hop bare with ifindex zero. As a result, the live terminal route behind that second static was not available as a usable ECMP member.

## What

- Build a family- and canonical-table-scoped route index before populating the FIB, so recursive static resolution is independent of route-record order in the snapshot.
- Resolve bare recursive gateways through same-table routes to terminal gateways and egresses, with cycle/depth/work guards. Discard, next-table, cross-table, and unresolved cases do not fabricate an egress. Pure cycles fail closed, but a mixed route that covers its own recursive gateway can self-match and resolve through a sibling member; B2 is explicitly tracked by follow-up #12613.
- Preserve the mixed route row and direct member, while baking each currently resolved terminal gateway into its recursive member. Remove the unused connected-only wrappers and their cross-module re-exports; keep connected inference as an internal helper.
- Add Rust v4/v6 FIB coverage for mixed rows, route-order permutations, a connected direct member without a neighbor, and recursion controls. No Go regression tests are included: the Go snapshot builder is unchanged by this Rust-only fix.

## Risk

The recursive backup can intentionally select a different egress zone. In the trust/untrust probe, the direct member resolved to trust ifindex 201 (`192.168.0.99`) and the recursive member resolved through the default route to untrust ifindex 202 (`203.0.113.1`). Of 256 flow hashes, 132 selected trust and 124 selected untrust; the base-state probe reported all 256 on trust while the recursive member was unusable. Operators must ensure the configured trust/untrust policy authorizes this re-steer. Quadratic recursive-build route scans are tracked separately in #12617. No live cluster or hardware was modified.
