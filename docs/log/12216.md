# #12216 — quarantine NAT and junos-host expanders

- **Base**: `83b5c955` (parent PR commit; the original RED probes ran on ancestor `a714c90d4`)
- **Why**: NAT address-name expansion could resolve the winning address of a colliding address/address-set name, silently drop dangling members, or keep a static alias while a declared feed was unready. The junos-host projection independently selected address/application winners on name collisions.

## Change

- NAT's shared `expandBookNameRecursive` rejects colliding names and poisons the WHOLE address-set closure if any member remains unresolved (for example, a dangling reference, an empty unbound set, an unusable static value without a ready feed value, or an unready feed binding). Ready feed prefixes remain supported. The raw-name fallback keeps a failed constraint non-empty, but a CIDR-shaped book name can parse as a literal prefix; making the fallback unparseable by construction is tracked by #12626.
- Junos-host address and application resolution checks collision metadata throughout nested closures. A reference that makes a term unrepresentable prevents that policy key from being marked rendered; the whole-ingress-zone gate may also suppress unrelated valid sibling denies.
- Added NAT cells with policy-path controls for empty nested closures and unusable addresses, plus a tolerant-compile regression for a user `application-set junos-http` nesting a colliding member. Updated the old #6143 partial-resolution assertions to the required whole-set poison behavior (#12216).

## Risk

When a junos-host term is marked unrepresentable, the whole ingress-zone
kernel program is suppressed, including otherwise valid sibling denies;
the #4168 warnings remain. A `from-zone any` or global term can suppress
the program in every applicable zone. The parent build rendered these
programs, so tolerant-loaded ambiguous configurations have weaker
direct-path deny enforcement after this change.

NAT-specific follow-ups are #12625 (static-NAT `prefix-name` collision),
#12626 (CIDR-shaped NAT fallback token), and #12627 (per-name NAT poison and
feed/static parity); none covers the whole-zone Junos-host enforcement
withdrawal described above.
