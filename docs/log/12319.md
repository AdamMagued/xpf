# #12319 — suppress unreachable rejects on stamped fabric ingress

## Why

The shared policy-reject gate suppressed only TCP RSTs on stamped fabric ingress. UDP fell through to ICMP construction, whose L2 builder reflects the inbound source MAC; the synthetic V1/V2 stamp is not the remote client's MAC. The resulting unreachable ICMP was queued, counted as sent, and reported as REJECT. The same source-MAC reflection existed in SYN-cookie SYN-ACK / ACK-RST replies.

## What

A shared forwarding predicate now recognizes a synthetic V1/V2 source stamp only when the ingress is a configured fabric link. The reject choke suppresses stamped-fabric replies before reply construction, TX-budget/rate-limit consumption, or sent counting. Existing event emission therefore reports the policy reject truthfully as DENY. Unstamped fabric UDP continues to return ICMPv4 or ICMPv6 port-unreachable to the inbound source MAC and logs REJECT.

The same predicate now suppresses stamped-fabric SYN-cookie SYN-ACK and ACK-RST replies before budget or sent-counter changes; the cookie leg was confirmed to have the same unreachable-source-MAC behavior during this slice.

Regressions cover V1/V2 UDP policy rejects, stamped UDP and ICMP filter rejects through the shared source gate, a producer-minted V2 stamp through the real poll path with an explicit ingress-primary precondition, an unstamped-fabric positive control, and stamped SYN-cookie SYN-ACK and ACK-RST suppression—including suppression before an exhausted TX budget is charged. The stamped-fabric TCP session-miss path remains covered by its existing #12051 test; no new session-miss regression was added in this change.

The R2 review fold pins both halves of the predicate on the cookie path and the IPv6 reject leg: an unstamped SYN on fabric ingress and a stamp-shaped source on native ingress both still receive a counted cookie SYN-ACK addressed to their source MAC, and an IPv6 stamped-fabric UDP policy reject queues no ICMPv6, counts nothing, and logs DENY, while its unstamped IPv6 control on the same fixture still queues ICMPv6 port-unreachable (1/4) to the client MAC and logs REJECT.

## Risk / residual

The reply suppression is limited to configured fabric ingress with a synthetic V1/V2 source stamp; unstamped fabric UDP remains an active, counted reject, while stamp-shaped native-ingress behavior is unchanged. No live cluster was exercised; poll behavior is covered by the real descriptor/poll fixture, and the SYN-cookie legs are covered by unit cells only. Suppressed replies are silent: no counter records them, matching the #12051 decision.
