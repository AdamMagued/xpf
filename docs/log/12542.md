# #12542 — flowexport family-ID suffix byte-ambiguous with template names

- **Timestamp**: 2026-10-10
- **Action**: Backslash-escape each hashed field in `stableExporterID` so a literal `|` in an instance/template name cannot forge a field boundary or the `|v6` family suffix.
- **Base**: `origin/master` `f9cb48ed8`
- **Files**: `pkg/flowexport/exporterid.go`, `pkg/flowexport/exporter_id_pipe_12542_test.go`, `pkg/flowexport/README.md`, `docs/log/12542.md`

## Why

GLM R1 F1 on PR #12364 (parent-reproduced): `stableExporterID` hashes
`protocol|instance|template` + literal `|v6` for inet6. An inet template
literally named `t|v6` hashes byte-identically to inet6 template `t` (both
3185142171). The config parser accepts quoted pipes with no charset gate, and
the ambiguity is general (any `|` shifts field boundaries).

## What

- `writeEscapedField`: `\` → `\\`, `|` → `\|` before joining. Injective:
  literal `|` bytes become pure separators; the family suffix is unforgeable
  by name content. NOT length-prefix (would renumber every inet id, breaking
  the #12148 migration pins 3503984933/2107433690) and NOT a charset gate
  (larger compiler surface, leaves the class half-fixed).
- Regression: exact issue pair (both protocols) + field-boundary pair +
  backslash/determinism battery. Names without `|`/`\` hash bit-identically
  (inet pins GREEN unchanged); only previously-ambiguous names get new ids.

## Validation

- RED: stashed exporterid.go → both pipe tests FAIL (pair == 3185142171).
- GREEN: `go test ./pkg/flowexport/ -run TestStableExporterID` 6/6 PASS
  (3 pre-existing incl. the #12148 migration pin + 3 new); full
  `pkg/flowexport` suite GREEN; gofmt/vet clean.

## Risk

Only names containing `|`/`\` — previously ambiguous/colliding — get new
ids (collectors see a new SourceID/ODID for exactly those groups). HA
symmetry preserved (still a pure function of the same four config-synced
inputs). No live cluster mutated.
