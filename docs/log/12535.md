# #12535 — ra -race failure in TestGoodbyeDebtDroppedWhenInterfaceIsAdvertisedAgain6777

- **Timestamp**: 2026-10-10
- **Action**: Join the live sender via `t.Cleanup(m.Clear)` before the seam-restore cleanup runs (LIFO), eliminating the `-race` DATA RACE.
- **Base**: `origin/master` `f9cb48ed8`
- **Files**: `pkg/ra/goodbye_retry_debt_6777_test.go`, `docs/log/12535.md`
- **Parent**: #12134 (Opus R1 residual R5 on #12351)

## Symptom

`go test -race ./pkg/ra` reports a data race: test cleanup
(`goodbye_retry_debt_6777_test.go:55`) writes `listenFn`/`ensureLinkLocalFn`
while a live sender owner goroutine reads them (`sender.go:269` in `openConn`,
`:377` in `listen`).

## Cause

The re-advertising `Apply` starts sender #2 via `go s.run()` and returns
without waiting for the owner to run `openConn`. The test asserts and returns
with that sender still running, so `t.Cleanup` restores the seam vars while
the owner is still reading them. Every other test in the file ends with all
senders joined (`Apply(nil)`/`Withdraw`) or starts none — this is the only
test with a live sender at teardown (including its post-re-advertise Fatal
paths).

## Fix (test-side only)

Registered `t.Cleanup(func() { _ = m.Clear() })` right after `m := New()` in
the affected test. It is registered after the probe's seam-restore cleanup,
so LIFO ordering joins the sender (`Clear` → `releaseDrain` → `<-s.stopped`)
before the seams are restored. No production change, no assertion change
(`Clear` is modeHard: emits no goodbye, probe counts untouched).

- `go test -race -count=1 ./pkg/ra` → ok (full suite green).
- `gofmt -l pkg/ra/` → empty; `go vet ./pkg/ra` → clean.

## Risk

None — test-only teardown ordering. No production code touched, no sleeps,
