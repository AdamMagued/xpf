- **Timestamp**: 2026-10-08

- **Files**: `userspace-dp/src/{session,server/helpers,afxdp,event_stream,protocol}/**`, `pkg/{dataplane,daemon,cluster}/**` (session-sync provenance and export estimate), `bpf/headers/xpf_common.h`, generated `pkg/dataplane/userspace_xdp_manifest.json`, regression tests, this record.

## Why

The Go coordinator can apply a canonical peer row and reject a duplicate
translated alias (`base=Applied`, `alias=RejectedReserve`), so the real
worker-import path retains only the canonical key. A translated packet may
therefore hit that canonical row; transient classification must use the
stored key, not the packet's forward tuple, or the canonical session is
torn down. For a genuinely stored translated alias, capture identity and
provenance before purge so NoLocalEntry SNAT validation can use the original
selectors: unchanged dynamic SNAT survives, while a later same-tuple static
collision still revokes.

## What

- Added provenance values `0=unknown/legacy`, `1=dynamic`, and `2=static` to the HA request and session open/update transports. Old requests and frames without the new field remain unknown.
- Stored provenance on imported and locally installed sessions; carried it through transient shared hits, revalidation, JSON deltas, and HA re-export. The resolver recovers the original tuple for identity-matched translated forward aliases before NoLocalEntry SNAT validation. Refreshes retain provenance only while the translated NAT decision is unchanged, and invalidate revalidation stamps so configuration changes are checked.
- Added a bit-10 “provenance known” marker beside the existing static-NAT bit. The marker distinguishes known dynamic/static state from legacy rows; unknown state clears both marker and static bit.
- Raised the owner-RG retained-delta estimate from 1856 to the measured 1863-byte JSON worst case after adding provenance.
- Added regressions for local incremental Open provenance, static and dynamic imports through the HA request parser, unchanged first-hit behavior, the translated transient alias/resolver path with session-identity collision rejection, and revocation after a same-tuple static collision. Binary open/update and JSON delta tests pin the cross-language values.
