# 12173 — qualify HA failover timing by mode and event

- **Date**: 2026-10-11
- **Why**: The PR-head docs presented a VRRP measurement as default failover
  timing, kept a stale 10s sync hold, and omitted ordinary private-RG shutdown
  behavior. A connected-sync recency guard changes the effective detection
  window.
- **What**:
  - Compiler default is private-RG election; it suppresses RETH VRRP.
    Runtime heartbeat defaults are 100ms × 5 = 500ms, lab config is
    200ms × 5 = 1s. While sync is connected and peer traffic is ≤2s old,
    timeout suppression is capped at 5s. Silent death with established sync
    takes max(threshold, remaining sync-recency window) plus up to one
    heartbeat tick: 0.5–2.1s at defaults / 1.0–2.2s in the lab, phase-dependent.
    Process exit that closes sync or idle sync falls through at the raw
    threshold. These are detection estimates, not restoration SLAs
    (`pkg/config/compiler_system.go:3132-3137`;
    `pkg/cluster/heartbeat.go:61-65,1916-1960`;
    `pkg/cluster/heartbeat_manager.go:790-832`;
    `pkg/daemon/daemon_ha_sync.go:170-206`).
  - VRRP and no-RETH startup holds are 30s, released early by bulk sync
    (`pkg/daemon/daemon_run_bringup.go:260-273`;
    `pkg/daemon/daemon_ha_noreth_hold.go:42-53`;
    `pkg/vrrp/manager.go:355-379`).
  - Legacy VRRP-backed RETH (`no-private-rg-election`, unless
    `no-reth-vrrp`) uses the configurable 30ms `reth-advertise-interval`;
    master-down formula is >90ms and <120ms at priorities 1–255. Planned
    legacy shutdown sends three priority-0 adverts; backup timer is 1ms and
    the run-loop test constraint is <50ms, not an SLA
    (`pkg/config/compiler_system.go:3119-3122`;
    `pkg/vrrp/vrrp.go:153-166`;
    `pkg/vrrp/instance_timing.go:112-128`;
    `pkg/vrrp/instance.go:770-807`;
    `pkg/vrrp/instance_rx.go:155-173`;
    `pkg/vrrp/instance_prio0_run_test.go:143-149`).
  - Ordinary private-RG shutdown sends no resign/transfer frame; after
    `rg_active` clears, peer promotion waits at least the heartbeat threshold
    and may be deferred by sync recency. Operator-requested private-RG
    failover uses a distinct explicit transfer path
    (`pkg/daemon/daemon_run_shutdown.go:418-428`;
    `pkg/cluster/manager.go:1026-1077`;
    `pkg/cluster/failover.go:447-450`;
    `pkg/cluster/election.go:1021-1042`).

    N3: docs name `reth-advertise-interval`, `heartbeat-interval`, and
