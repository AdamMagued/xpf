- **Residual risk**: Only the seed's low byte decides relative shard placement.
  The seed is XORed into the FNV offset at `mod.rs:209`, and the
  fixed-multiplier finalizer at `mod.rs:227-228` rotates all keys together.
  Thus a precomputed collision set still wins ~1 boot in 256; any low-byte
  leak restores offline targeting. Keyed-placement hardening is tracked in
  follow-up #12602. Collisions discovered through online observation were
  never prevented. Existing fail-closed availability impact and bounded
  shard/domain/sender capacities remain unchanged. Project-wide validation is
  deferred to the parent campaign.
