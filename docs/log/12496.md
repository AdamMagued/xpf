# #12496 — established GRE-local permit hit misses after teardown

Parent: #12258 review; this change does not expand or close #12258.
Sibling: #12497. Both regressions are fixed by the same #12056 revalidation
correction; the #11297 VLAN fixture issue is separate from #12496.

Base: `origin/master` at `bbbbf9dee`.

## RED and probe (firsthand)

On clean base, the exact cell
`afxdp::tests_gre_local_delivery::poll_descriptor_junos_host_permit_established_hit_counts_once`
failed at `tests_gre_local_delivery.rs:430`: established ACK #1 had
`session_hit=0`, expected 1. The SYN had installed a session, and ACK #0 had
hit it before the session disappeared.

A temporary local probe (removed before commit) recorded the cause:

```
SYN: local=1 create=1 sessions=1
stored row: LocalDelivery, tunnel_endpoint_id=0, install identity=(0,0)
ACK #0: hit=1 filter_revoked=1 policy_revoked=0 host_inbound_deny=0 sessions=0
ACK #1: hit=0 miss=1 create=0 sessions=0
ACK #2: hit=0 miss=1 create=0 sessions=0
```

The established ACK was revoked by the session-hit filter/route revalidation
path before host-bound policy accounting could run.

## Triage: shared product cause, not #11297 VLAN handling

The packet fixture uses ingress ifindex 24 (`reth1.0`) and default VLAN 0, not
a tagged-only child. The SYN and first ACK reach session processing, so the
post-#11297 VID-0 poll-head guard is not the cause.

In `poll_descriptor/filter.rs::revalidate_static_pbr_route_on_session_hit`,
#12056's stable-local check recognizes the ordered ingress-primary-address and
interface-NAT local miss arms. This flow's local destination is owned by a
different interface and resolves through the FIB local arm instead. The
revalidator therefore bypassed the identity fast path for a stored
non-tunneled `LocalDelivery`, then returned a route transition even though the
fresh FIB resolution and `(0,0)` route identity matched the stored session.
`poll_descriptor/mod.rs` converts that non-steer transition into a discard,
increments `filter_revoked_sessions`, and deletes the session. This is the same
product defect exposed by #12497's established DNAT-to-self ACK.

The fix requires equality of both the freshly resolved forwarding result and
the stored route identity before retaining a FIB-local session. A new
fail-on-revert #12056 cell reproduces this non-ingress local-address shape;
PBR retarget and address-removal changes still return a route transition.
