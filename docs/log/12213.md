# #12213 — isolate apply-time interface revalidation

- **Timestamp**: 2026-10-12 (`fix/12213-campaign-pub`; rebased onto `3769f4016`)
- **Action**: isolate interface compaction from retained snapshots and classify/store the exact interface plan sent to the helper.

## Why

`requestApplySnapshotLocked` compacted `Interfaces` in place. Several publishers shallow-copied `ConfigSnapshot`, so a failed partial publish could mutate the retained snapshot's shared backing array while leaving its stored content hash unchanged. Compile and deferred-publish plan decisions also used a key computed before this revalidation.

## What

- Clone the interface rows and each non-nil `LinkUp` pointer before apply-time compaction. Keep the prepared sender separate so Compile and deferred sync can revalidate once before plan-key classification and send that same struct.
- On ACK, retain the sent interface rows and record its plan key and content hash across Compile, deferred sync, scheduler, worker-arm, link-refresh, route-overlay, and capture-authority publishes. Move route/capture hash dedup behind the interface sample.
- Promote regressions for deferred-tick sampling/plan gating, Compile classification, and scheduler/worker-arm ACK writeback; the retained authority must match exactly the interface rows sent.
- Gate deferred XSK-startup ticks against the retained plan before interface sampling, then sample and re-gate only admitted publishes; a deferred tick samples nothing.
- Remove the unprepared fail-closed wrapper and boolean plumbing; test callers explicitly prepare snapshots before invoking the prepared publisher.

## Risk

- No live-cluster or hardware validation was performed. No wire fields or protocol version changed.
- A deferred tick intentionally defers a retained/live plan divergence; normal Compile and partial-publish paths retain prepared rows, so this pair is unreachable in ordinary flows.
- Link churn after the single apply-time sample can leave a stale ifindex until the next link-event refresh; this is self-healing and inherent to the single-sample contract.
