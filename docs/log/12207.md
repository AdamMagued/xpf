# Issue #12207 — pin image-roll mixed-base refusal

## Why

The `_gate_mixed_base` predicate had direct vectors, but image-roll suites only exercised passing manifests. The `cmd_image_roll` orchestrator's refusal before drain/recreate, operator override, and lease cleanup on a pre-mutation failure were therefore unpinned. Production behavior is alleged correct; this is a test-only backfill, not a production correction.

## What

Added `scripts/deploy/test_xpf_deploy_roll_gate_refusal.py`. It stages a manifest/checksum chain with an incompatible session-sync version and drives `cmd_image_roll`, asserting the failure reason, no drain/recreate/rejoin, and release of both acquired leases. Signature verification is stubbed following the existing signed-manifest tests; checksum binding and signed qcow2 digest resolution use the real helpers.

The explicit `--allow-session-drop` case proves the orchestrator reaches the first drain with `--allow-mixed-ha`, then stops at the drain-command boundary rather than fabricating success from an incompatible daemon. The compatible-manifest drain-argv tests are the M2 and M3 kill cells: the first drain omits `--allow-mixed-ha`, and the second includes it only when the feature probe succeeds; an unsupported xpfd omits the flag.

## Validation

- STEP-0 base: PR parent `83b5c955335f16d8c7835f206b210ce3ae1a5fe5`; enforcement was already present and there was no roll-level failed-gate fixture.
- RED-before: all four D8-12 mutants M1-M4 survived all 24 pre-existing `scripts/deploy/test_*.py` files (323 tests).
- GREEN-after: new module — 5 tests passed. M1 (roll ignores a failed gate) was killed by 2 tests; M2 (first drain always flagged) by 2; M3 (flag without the feature probe) by 1; and M4 (waiver no longer relaxes the drain) by 1. X1 (recreate before refusal) and X2 (pre-mutation lease-release leg) were each killed by 1 test.
- Scoped gate/identity/lease/digest/daemon-hold suites — 99 tests passed.
- Broader deploy Python suite (`python3 -m unittest discover -p 'test_xpf_deploy_*.py' -q`) — 328 tests passed; no broader reds required same-base attribution.

## Risk / residual

No production code, Go drain behavior, Debian changelog, live node, or hardware was changed or exercised. The test pins Python orchestrator wiring; the Go session-sync drain gate remains an independent runtime backstop and is not simulated as successfully accepting an incompatible peer.
